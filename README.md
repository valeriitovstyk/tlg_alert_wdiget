# Тривога · Київ / Львів — Telegram-віджет

Віджет у бульбашці чату Telegram (на [widget-sandbox](https://github.com/TelegramMessenger/widget-sandbox), профіль 1, SDK v1):
для Києва і Львова — тривога так/ні, скільки шахедів і ракет летить курсом на місто (і скільки вже поруч), КАБи, загроза балістики (МіГ-31К).

```
NEPTUN (neptun.in.ua) ──15 с──▶ bot/bot.py ──editSharedWidgetData──▶ Telegram ──▶ віджет у кожному чаті
```

- `widget/widget.html` — сам віджет (≈1.9 КБ після zlib, ліміт 4 КБ). У мережу не ходить: малює `publicData`, який пише бот, і стежить за ним (`watchPublicData`).
- `bot/bot.py` — бот, лише стандартна бібліотека Python. Один **спільний** віджет: одне оновлення стану — і він змінюється в усіх чатах. Якщо Bot API ще не має `sendWidget`, бот сам переходить на **текстове повідомлення**, яке редагує (працює на будь-якому Telegram).
- `.github/workflows/bot.yml` — безкоштовний запуск бота в GitHub Actions, без власного сервера.
- `index.html` — та сама картина як вебсторінка (бонус).

## Запуск

1. @BotFather → `/newbot` → токен.
2. Репозиторій → Settings → Secrets and variables → Actions:
   - **Secret** `BOT_TOKEN` — токен.
   - **Variable** `CHAT_IDS` (необов'язково) — id чатів через кому, куди одразу надіслати й закріпити віджет. Можна не задавати: напиши боту `/start` (або додай його в сімейну групу і напиши `/alert`).
   - Для бета-API з віджетами: `BOT_API` = `https://api.telegram.org/beta`, `TEST_ENV` = `1` (тестове середовище Telegram).
3. Actions → **alert-bot** → Run workflow. Далі він перезапускається сам.

Локально: `BOT_TOKEN=… python3 bot/bot.py`.

## Стан віджета (`publicData`, ≤ 1024 байти)

`{"r":ревізія,"t":unix,"c":[Київ,Львів],"g":[шахеди,ракети,балістичні,МіГ-31К]}`, де місто — `[тривога,з (unix),шахеди курсом,з них поруч,ракети курсом,з них поруч,КАБи,балістика]`.
«Курсом на місто»: ціль за ≤ 60 км, або її курс відхиляється від напрямку на місто ≤ 25° (шахеди до 450 км, ракети до 1200 км).

Дані: Карта повітряних тривог — [NEPTUN](https://neptun.in.ua/). Це агрегатор, а не офіційна система оповіщення; орієнтуйтеся на офіційні сигнали тривоги.
