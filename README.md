# Тривога · Київ / Львів

Дашборд стану повітряної тривоги для Києва і Львова: тривога так/ні, скільки шахедів і ракет летить курсом на місто, КАБи, загроза балістики (МіГ-31К).

Одна статична сторінка, без сервера: браузер раз на 10 с бере дані з відкритого API [NEPTUN](https://neptun.in.ua/) (`/api/v1/alerts`, `/api/v1/threats`).

- `?demo` в кінці адреси показує вигадану тривогу, щоб побачити вигляд.
- На Android: відкрити в Chrome → ⋮ → «Додати на головний екран».

Дані: Карта повітряних тривог — NEPTUN (https://neptun.in.ua/). Це агрегатор, а не офіційна система оповіщення; орієнтуйтеся на офіційні сигнали тривоги.
