# Тривога · Київ / Львів — Telegram-бот

Одне закріплене повідомлення в Telegram, яке бот тихо оновлює (без сповіщень, без нових повідомлень):

```
🕐 00:40

🔴 Київ — ТРИВОГА (40 хв)
   🛩 шахедів курсом: 6
   ⏱ найближчий шахед: ~23 хв
   🚀 ракет курсом: 0
   ⚠️ Загроза балістики
   💥 вибухи / ППО, 3 хв тому (з каналів)

🟢 Львів — тривоги немає (але: 2 шахед. курсом, ~36 хв)

⚠️ З каналів: загроза Кинджалів (12 хв тому), стратегічна авіація (Ту-95/160/22) (30 хв тому)
```

- Дані: [NEPTUN](https://neptun.in.ua/) — тривоги, цілі (координати, курс, швидкість) і повідомлення моніторингових каналів, раз на 15 с.
- «Курсом на місто»: ціль за ≤ 60 км, або її курс відхиляється від напрямку на місто ≤ 25° (шахеди до 450 км, ракети до 1200 км). Підліт — відстань / швидкість (150 км/год, якщо NEPTUN не дав).
- «З каналів» (Орєшнік, Кинджал, Ту-95/160/22, Калібр — 45 хв; вибухи / ППО в місті — 20 хв) — це текст людей, а не радар.
- `bot/bot.py` — лише стандартна бібліотека Python. `.github/workflows/bot.yml` — безкоштовний запуск у GitHub Actions.

## Запуск

1. @BotFather → `/newbot` → токен.
2. Settings → Secrets and variables → Actions → secret `BOT_TOKEN`. Settings → Actions → General → Workflow permissions: **Read and write**.
3. Actions → **alert-bot** → Run workflow. Далі він перезапускається сам.
4. Написати боту `/start` (або додати в групу й написати `/alert`).

Дані: Карта повітряних тривог — NEPTUN (https://neptun.in.ua/). Це агрегатор, а не офіційна система оповіщення.
